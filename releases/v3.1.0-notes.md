## downterm 3.1.0

Minimal **terminal** UI only. The separate window GUI is gone.

### Use
1. Copy a video link  
2. Run `downterm` (or `download.bat`)  
3. Press **1** for best video  

### PATH
- Menu **7** or `download.bat --install`  
- Adds this folder to **user PATH**  
- New terminals: type `downterm`  
- Linux: `./download.sh --install` → `~/.local/bin/downterm`

### Not in this release
- No WinForms / click window  
- No required CLI flags for normal use
