## downterm 3.4.0

### Actionable cross-platform errors

Linux and macOS now report the same actionable error codes as Windows for common failures:

- `ERR-08` — HTTP 4xx from server
- `ERR-09` — HTTP 5xx from server
- `ERR-10` — connection timed out or refused
- `ERR-11` — ffmpeg executable missing
- `ERR-12` — deno runtime missing

This makes network and missing-tool failures easier to diagnose without reading raw yt-dlp output. The regression suite uses a local fake yt-dlp process, so it does not download media or require network access.

### Setup and use

Windows:

```bat
setup.bat
download.bat --version
```

Linux/macOS:

```bash
chmod +x setup.sh
./setup.sh
./download.sh --version
```
