## downterm 3.2.0

Stable terminal release — focused on **`downterm` working in PowerShell**.

### Type this in a new PowerShell

```powershell
downterm
```

### One-time PATH install

1. Run `download.bat`  
2. First launch asks **Y/N** to add PATH (or press **7** any time)  
3. **Close the window**  
4. Open a **new** PowerShell  
5. Type `downterm`

Also: `download.bat --install`  
Undo: `download.bat --uninstall`

### What changed in 3.2.0

- First-run PATH install prompt  
- **`downterm.ps1`** entrypoint (PowerShell-friendly)  
- Stronger `install-path.ps1` (cmd + ps1 shims, env broadcast)  
- Menu tip if PATH not installed yet  
- Help text for “not recognized” errors
