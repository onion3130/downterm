## downterm v2.4

### New
- **p** paste URL from clipboard
- **h** history (pick a past URL)
- **o** open download folder
- **i** info preview (title / duration) then optional download
- Quality: **4K** (`k`) and **1440p** (`2`)
- Optional **English subtitles** (embed)
- Optional **SponsorBlock** segment removal
- Optional **force overwrite**
- Safer filenames: `title [id].ext`
- Config keys: `SUBS`, `FORCE`, `SPONSORBLOCK` (see `downterm.conf.example`)
- Flags: `--subs` `--force` `--sponsorblock`
- Linux/macOS parity for redo, audio quality, and new commands

### Run
- Windows: `download.bat`
- Linux/macOS: `chmod +x download.sh filter.sh && ./download.sh`

### Example
```bat
download.bat "https://youtube.com/watch?v=..." --mode=video --quality=1080 --subs
```
