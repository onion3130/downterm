## downterm 3.1.1

Stable terminal release. **Type `downterm` after PATH install.**

### Launch with one word

```bat
downterm
```

**Windows**
1. Run downterm once  
2. Press **7** (*add to PATH*) — or `download.bat --install`  
3. Open a **new** terminal  
4. Type `downterm`

**Linux / macOS**
```bash
./download.sh --install
# new shell:
downterm
```

### Everyday use
1. Copy a video link  
2. `downterm`  
3. Press **1** for best video  

### Notes
- Terminal number menu only (no window GUI)  
- `downterm.cmd` is the Windows entrypoint  
- `install-path.ps1` manages user PATH  
- Undo: `download.bat --uninstall` / `./download.sh --uninstall`
