## downterm 4.1.0

The "try it anywhere" release. Fixes CI, adds real self-update, and the link prompt is now paste-or-Enter instead of silently grabbing the clipboard.

### Paste prompt (the fix for wrong links)

Menu options 1 / 2 / 3 / 0 now **prompt you to paste or type the link**. If a link is already in your clipboard it's shown as a hint and `Enter` accepts it - but you always get a chance to replace it. A wrong or non-URL value is caught before anything is downloaded.

### Real self-update

`downterm --update` no longer just prints "a newer release is available." It:

- refreshes yt-dlp / deno to the pinned, hash-verified versions
- downloads the latest downterm release archive
- replaces `download.bat` / `download.sh` / `filter.sh` / `setup.ps1` in place

Restart downterm and you are on the new version.

### CI is green again

`download.sh --setup` / `download.bat --setup` had a bug: the CLI flag fell through into the interactive menu and hung forever in CI (that's why the badge was stuck "cancelled"). Both now run the pinned-binary fetch non-interactively and exit. Workflow steps got `timeout` guards and were updated for the new filter arg positions.

### Misc

- `NO_COLOR`, `TERM=dumb`, or piped output now disable ANSI colors automatically
- `--version`, menu banners, and `--update` self-check all report `4.1.0`

### Quick start

Windows:

```bat
setup.bat
download.bat --version
```

Linux/macOS:

```bash
chmod +x setup.sh
./setup.sh
./download.sh --version
```
