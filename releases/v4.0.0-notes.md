## downterm 4.0.0

downterm is now installable in one command on every OS, and it handles playlists, restricted content, and multiple audio formats.

### Install in one command

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/onion3130/downterm/main/install.ps1 | iex
```

Linux / macOS:

```bash
curl -fsSL https://raw.githubusercontent.com/onion3130/downterm/main/install.sh | bash
```

Then open a new terminal and type `downterm`. The installer pulls the latest release and runs the pinned, SHA-256-verified tool setup.

### New features

- **Playlist picker** - menu option `0`: paste a playlist, choose `all`, `1-3`, or `2,5,7`, then download as video or audio
- **Cookies** - `downterm --cookies=cookies.txt` (or `COOKIES=` in `downterm.conf`) unblocks age-restricted / members-only / private content
- **Audio formats** - option `3` now asks for `mp3` / `m4a` / `opus` / `wav`; `--audio-format=flac|aac` also available
- **Title + thumbnail embedded** in saved files by default (`--no-embed` to skip)
- **Self-update** - `downterm --update` refreshes yt-dlp to the pinned, hash-verified version and checks whether a newer downterm wrapper exists
- **`ERR-14`** - a requested cookies file that doesn't exist now gets a clean, documented error code

### Maintenance

- `downterm.conf` new keys: `COOKIES`, `AUDIO_FORMAT`, `EMBED`
- Regression suite extended for `ERR-13`, `ERR-14`, and the new playlist/embed/audio args

### Quick start

Windows:

```bat
setup.bat
download.bat --version
```

Linux/macOS:

```bash
chmod +x setup.sh
./setup.sh
./download.sh --version
```
