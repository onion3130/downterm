## downterm 3.3.0

### Setup scripts (recommended)

**Windows** — double-click or run:

```bat
setup.bat
```

**Linux / macOS:**

```bash
chmod +x setup.sh && ./setup.sh
```

These scripts:
1. Install tools when missing (yt-dlp / ffmpeg / deno)  
2. **Always add PATH** so you can type `downterm`  

Then open a **new** terminal and run:

```text
downterm
```

### Manual PATH (anytime)

You can install or re-install PATH without re-downloading tools:

| Windows | Linux / macOS |
|---------|----------------|
| `setup.bat -PathOnly` | `./setup.sh --path-only` |
| `download.bat --install` | `./download.sh --install` |
| menu → **7** | menu → **7** |

### Use

1. Copy a video link  
2. `downterm`  
3. Press **1** for best video
